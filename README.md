# 시각 알림 카운트다운

**바로 사용하기: <https://deafwith.github.io/countdown/>**

행사·강의·설교·발표에서 남은 시간을 **큰 숫자**로 보여주고, 남은 시간에 따라 **배경색 변경**과 **배경 점멸**로 알려주는 웹앱입니다. 소리 없이 화면만 보고 시간 상황을 알 수 있습니다.

- 윈도우·맥(크롬, 엣지, 사파리), 갤럭시탭(크롬, 삼성 인터넷), 아이패드(사파리)에서 같은 주소로 사용
- 로그인·서버·데이터베이스 없음. 설정은 각 기기의 브라우저에 저장
- 홈 화면에 추가(PWA) 가능, 한 번 연 뒤에는 오프라인에서도 동작

---

## 1. 기술 선택과 이유

| 선택 | 이유 |
|---|---|
| **순수 HTML·CSS·JavaScript** (빌드 도구·프레임워크 없음) | 파일을 그대로 올리면 끝. npm 설치·빌드 과정이 없어 몇 년 뒤에도 고치기 쉽습니다. |
| **정적 호스팅** (GitHub Pages, Netlify, Cloudflare Pages 등) | 무료이고 HTTPS가 자동이라 PWA·화면 꺼짐 방지 조건을 바로 만족합니다. |
| **서비스 워커 + 매니페스트** | 홈 화면 설치와 오프라인 사용. |
| **로직 3분리** | 시간 계산(`timer.js`), 알림 판정(`alerts.js`), 설정 저장(`settings.js`)이 화면 코드(`app.js`)와 분리되어 있어 각각 테스트하고 고칠 수 있습니다. |

## 2. 파일 구조

```
카운트다운/
├── index.html             화면 구조 (메인, 설정, 확인창, 미리보기)
├── css/style.css          디자인, 점멸 애니메이션, 반응형/발표 모드
├── js/timer.js            카운트다운 로직 (종료 예정 시각 기준 계산, 일시정지/복원)
├── js/alerts.js           알림 판정 (종료 → 점멸 → 배경색 → 기본), 글자색 대비 계산
├── js/settings.js         설정 기본값·검증·저장 (저장소를 못 쓰면 메모리로 대체)
├── js/app.js              화면 제어, 키보드, 전체화면/발표 모드, 화면 꺼짐 방지, 미리보기
├── sw.js                  서비스 워커 (오프라인 캐시)
├── manifest.webmanifest   PWA 정보 (이름, 아이콘, 색)
├── icons/                 앱 아이콘 (SVG, PNG 192/512, 마스커블, 애플 터치 아이콘)
└── tests/logic.test.js    로직 자동 테스트 (Node.js)
```

## 3. 로컬에서 실행하기

### 가장 간단한 방법 (맥)
1. 터미널을 열고 폴더로 이동한 뒤 서버를 켭니다.
   ```bash
   cd ~/카운트다운
   ```
   ```bash
   python3 -m http.server 8000
   ```
2. 브라우저에서 `http://localhost:8000` 을 엽니다.
3. 끝낼 때는 터미널에서 `Ctrl + C`.

### 윈도우
1. [python.org](https://www.python.org/downloads/)에서 파이썬을 설치합니다(설치 화면에서 “Add python.exe to PATH” 체크).
2. 폴더에서 주소창에 `cmd` 입력 → 엔터 → `python -m http.server 8000` 실행.
3. 브라우저에서 `http://localhost:8000`.

> `index.html`을 더블클릭해서 열어도 카운트다운 자체는 동작합니다. 다만 이 경우(`file://`)에는 **오프라인 캐시·홈 화면 설치가 되지 않습니다.** 서비스 워커는 **HTTPS** 또는 **localhost** 에서만 동작하기 때문입니다.

### 같은 와이파이의 태블릿에서 미리 보기
`python3 -m http.server 8000 --bind 0.0.0.0` 로 켜고, 태블릿에서 `http://(이 컴퓨터의 IP):8000` 을 엽니다. 이때는 HTTPS가 아니라서 **오프라인·설치·화면 꺼짐 방지는 동작하지 않을 수 있습니다.** 실제 사용은 아래처럼 배포해서 HTTPS 주소로 여세요.

### 로직 테스트
Node.js 18 이상이 있으면:
```bash
node --test tests/logic.test.js
```

## 4. 웹에 배포하기 (무료, HTTPS 자동)

### 방법 A — Netlify Drop (가장 쉬움, 가입 후 드래그 한 번)
1. <https://app.netlify.com/drop> 접속 후 로그인.
2. `카운트다운` 폴더를 통째로 화면에 끌어다 놓기.
3. 생성된 `https://….netlify.app` 주소를 각 기기에서 엽니다.

### 방법 B — GitHub Pages
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다(웹에서 “Add file → Upload files”로 끌어다 놓아도 됩니다).
2. 저장소 **Settings → Pages → Build and deployment** 에서 Source를 “Deploy from a branch”, Branch를 `main` / `(root)` 로 저장.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.

### 방법 C — Cloudflare Pages
대시보드 → Workers & Pages → Create → Pages → “Upload assets”에서 폴더를 올립니다.

> 모든 경로가 상대 경로라 하위 폴더 주소(GitHub Pages)에서도 그대로 동작합니다.

### 업데이트할 때
파일을 고쳐서 다시 올리면, 사용자는 **앱을 한 번 연 다음 다시 열 때** 새 버전을 보게 됩니다(먼저 캐시본을 보여주고 뒤에서 새 파일을 받아두는 방식). 파일을 추가·삭제했다면 `sw.js` 맨 위의 `CACHE = 'visual-countdown-v1'` 숫자를 `v2`처럼 올려 주세요.

## 5. 홈 화면에 추가 (PWA)

HTTPS 주소에서 열어야 합니다.

- **아이패드 (사파리)**: 공유 버튼 → “홈 화면에 추가”.
- **갤럭시탭 (크롬)**: 메뉴(⋮) → “홈 화면에 추가” 또는 “앱 설치”. **삼성 인터넷**: 메뉴 → “현재 페이지 추가” → 홈 화면.
- **윈도우·맥 (크롬/엣지)**: 주소창 오른쪽의 설치 아이콘 또는 메뉴 → “앱 설치”.
- **맥 (사파리 17 이상)**: 파일 메뉴 → “Dock에 추가”.

설치 후 한 번 열어 두면 이후에는 인터넷 없이도 열립니다.

## 6. 사용법

| 동작 | 마우스/터치 | 키보드 |
|---|---|---|
| 시작 / 일시정지 / 이어서 시작 | 가장 왼쪽 흰 버튼 | **Space** |
| 전체화면(발표 모드) 켜기/끄기 | 전체화면 버튼 | **F** |
| 설정·발표 모드 닫기 | 취소 / 발표 모드 종료 | **Esc** |
| 초기화 | 초기화 버튼 (진행 중이면 확인을 받음) | — |

- 대기 상태에서는 화면 아래 **5·10·15·20·30·60분** 버튼으로 바로 시간을 바꿀 수 있고, “직접 입력”으로 분·초를 넣을 수 있습니다.
- 입력창에 글자를 쓰는 중에는 단축키가 동작하지 않습니다.
- 실행 중 설정을 누르면 “먼저 일시정지” 안내가 나옵니다.
- 발표 모드에서는 3초 동안 조작이 없으면 버튼이 숨겨지고, 마우스를 움직이거나 화면을 탭하면 다시 나타납니다. 키보드(Tab)로 버튼에 포커스가 있으면 숨기지 않습니다.
- 전체화면을 지원하지 않는 브라우저(예: 아이폰 사파리)에서는 브라우저 화면 안에서 숫자를 최대한 크게 보여주는 발표 모드로 대신합니다.

### 알림 규칙
- 남은 시간이 설정값 **이하**가 되면 적용합니다. 우선순위는 **시간 종료 → 점멸 → 배경색 변경 → 기본 배경**.
- 점멸은 선택한 색과 그 색의 어두운 톤 사이를 **2초(느리게) 또는 1.5초(보통)** 주기로 부드럽게 오갑니다. 숫자와 문구는 점멸하지 않습니다.
- 상태는 색만이 아니라 **‘마무리 시간’·‘종료 임박’·‘일시정지’·‘시간 종료’** 글자로도 표시합니다.
- 글자색(흰색/검정)은 배경색에 맞춰 자동으로 고릅니다. 노랑·주황처럼 밝은 색은 검정 글자를 쓰고, 점멸의 어두운 톤도 글자가 읽히는 만큼만 어둡게 합니다.
- 기기에 **‘동작 줄이기’** 가 켜져 있으면 점멸 대신 점멸 색상의 고정 배경 + ‘종료 임박’ 문구로 알립니다(설정에서 “그래도 점멸 사용” 선택 가능).
- 시간 표시는 1시간 미만 `MM:SS`, 1시간 이상 `HH:MM:SS` 입니다.

### 화면 꺼짐 방지
지원하는 브라우저에서는 실행 중 화면이 꺼지지 않게 요청하고, 일시정지·종료·초기화 시 해제합니다. 하지만 **모든 기기에서 보장되지 않습니다.** 미지원이거나 요청이 거절되면 짧은 안내가 나오니, 그때는 기기의 자동 잠금(화면 꺼짐) 시간을 늘려 주세요.

## 7. 시간 정확도와 안정성 (구현 방식)

- 매초 숫자를 1씩 빼지 않고, **종료 예정 시각 − 현재 시각**으로 남은 시간을 계산합니다. 타이머가 늦게 불려도 오차가 쌓이지 않습니다.
- 다음 갱신은 “다음 초가 바뀌는 순간 직후”로 한 번만 예약하며, 중복 예약은 항상 취소합니다.
- 일시정지 시 남은 시간을 밀리초 단위로 저장하고, 이어서 시작할 때 종료 예정 시각을 다시 계산합니다.
- 다른 탭·앱에서 돌아오면(`visibilitychange`, `pageshow`, `focus`) 즉시 다시 계산하고 점멸 위상도 남은 시간에 맞춥니다. 이미 끝났으면 바로 ‘시간 종료’를 표시합니다.
- 상태가 바뀔 때마다 브라우저 저장소에 기록하므로 새로고침해도 실행 중·일시정지 상태와 남은 시간이 복원됩니다.
- 브라우저 저장소를 쓸 수 없는 환경(일부 사생활 보호 모드 등)에서는 메모리에만 보관하고, 설정 화면에 안내를 표시합니다.
- 화면 읽기 프로그램에는 매초 시간을 읽지 않고, 시작·일시정지·알림 단계 변화·종료만 알립니다.

## 8. 확인한 내용 (정직한 테스트 기록)

### 자동 테스트 — `node --test tests/logic.test.js` : 21개 모두 통과
시간 표시 형식, 종료 예정 시각 기준 계산, 0초에서 정지, 일시정지·이어서 시작 정확도, 중복 시작 방지, 초기화, 새로고침 복원(실행 중/일시정지/그사이 종료), 사용 예시 1~5, 일시정지 중 점멸 고정, 동작 줄이기, 점멸 속도, 설정 안내 문구, 글자 대비(프리셋 색 4.5:1 이상), 입력 검증(0초·음수·소수·문자·60초 이상 거부), 깨진 설정 복구, 저장소 불가 시 동작.

### 브라우저에서 직접 확인 — **맥의 크로미움 기반 브라우저 1종(Claude 데스크톱 앱 내장 브라우저)에서만**
20초 카운트다운 / 배경색 변경 10초 / 점멸 5초 설정으로:
- [x] 기본 카운트다운과 00:00 ‘시간 종료’, 종료 배경색 고정·점멸 해제
- [x] 기본 → ‘마무리 시간’(빨강) → ‘종료 임박’(점멸) 전환
- [x] 일시정지(시간·점멸 정지, 알림 색 고정, ‘일시정지 · 마무리 시간’ 표시) 및 이어서 시작
- [x] 일시정지·실행 중 상태에서 새로고침 후 복원
- [x] 실행 중 초기화 확인창, 초기화 후 기본 화면 복귀
- [x] 실행 중 설정 열기 → 일시정지 안내
- [x] 설정 저장 / 취소(저장값 변화 없음)
- [x] 미리보기가 실제 타이머에 영향 없음, 끝나면 설정 화면으로 복귀, Esc로 미리보기만 종료
- [x] 전체화면 미지원 환경을 흉내 낸 발표 모드, 3초 후 버튼 숨김, 마우스 이동 시 다시 표시, Esc로 종료
- [x] 화면 크기 768×1024, 1024×768, 375×812, 812×375에서 숫자·버튼 잘림 없음, 가로 스크롤 없음, 버튼 높이 48px 이상 (`01:00:00` 포함)
- [x] 서비스 워커 등록 → 서버를 끈 상태에서 새로고침해도 앱이 열리고 실행 중 타이머가 복원됨
- 사용 예시 2~5(동시 점멸, 배경색만, 점멸만, 알림 없음)는 자동 테스트로 판정 로직을 확인했습니다.

### 확인하지 못한 것
- **실제 아이패드, 갤럭시탭, 윈도우 PC, 사파리, 파이어폭스, 삼성 인터넷에서는 테스트하지 않았습니다.**
- 실제 전체화면 API 진입(브라우저 보안상 사용자 조작이 필요), 실제 기기의 화면 꺼짐 방지 동작(테스트 브라우저에서는 요청이 거절되어 안내 문구가 표시되는 것만 확인), 홈 화면 설치, 기기의 ‘동작 줄이기’ 실제 연동, 탭이 실제로 숨겨졌을 때의 동작(계산 방식상 정확해야 하지만 테스트 브라우저에서 탭 숨김 상태를 재현하지 못함).

실제 기기에서는 위 체크리스트를 20초 / 10초 / 5초 설정으로 한 번씩 확인해 보시길 권합니다.
